Pin template — 3 variants, 1000 × 1500

For Marketing (Phase 4). One pin per idea, deep-linked to its idea page. The illustration is the idea’s vertical file; the title is an HTML text layer on top. Illustrations shown here are placeholders — final pins are exported only when the final art exists.

Variants

How to make a pin

  1. Open pin.html?slug=<slug>&variant=a (or b, c). The title, room and facts come from pin-data.js, which is generated from src/data/ideas.json — never retype a title.
  2. Optional: &title=… for an approved alternative title, &kicker=… for another kicker, &kicker=none to hide it.
  3. Export at exactly 1000 × 1500 px (browser window or screenshot tool set to that size). Save as PNG.
  4. The pin links to /ideas/<slug>/. The pin description is text on Pinterest, not in the image.

Rules

TitleMaximum 40 characters and 3 lines. Up to 16 characters = largest size, 17–24 = medium, 25–32 = small, 33–40 = smallest. The template picks the size from the length. All 60 idea titles fit (longest: 32 characters). Sentence stays as written in the data: no ALL CAPS, no emoji.
KickerMaximum 22 characters, one line, facts only (time and mess from the data). No prices, no “#1”, no counts, no “as seen on”.
Text layerTitle, kicker and site name are HTML text. Never put words, letters or numbers inside the illustration file.
Safe areas60 px outer margin. Title band: y 60–480. Illustration focal area: y 560–1440 — no text over it.
Site markSmall, once, top of the band: mascot face + site name (“Daily Elf Magic” is a placeholder). Never a third-party logo or brand name.
Colour pairsA on light rooms: night-blue text on the wall, red kicker with snow text (6.41:1). A on night blue: cream text (12.25:1), gold kicker with night text (5.87:1). B: snow on red (6.41:1), gold kicker with night text. C: night on snow (12.88:1), red kicker text (6.41:1). Never gold text on cream or on red.
FontsFredoka Bold for the title, Nunito Bold for kicker and mark. This file makes no network request: install both fonts on the machine that exports the pins, otherwise the fallback (a rounded system font) is used.
Variant choiceA is the default. Use B when the wall colour is pale and the pin needs more punch. Use C for goodbye, arrival and note-driven ideas. Keep one variant per board row so the grid looks planned.
